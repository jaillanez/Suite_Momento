# Momento

Plataforma nueva para acompañar y organizar el cuidado de personas mayores en residencias y domicilios, inicialmente orientada a Argentina y Uruguay.

Este repositorio comienza como un proyecto greenfield. El sistema anterior de 2014 sirve únicamente como referencia histórica para identificar problemas y necesidades; no se copiarán su código, arquitectura ni base de datos.

## Estado

Estamos definiendo el producto y sus procesos. La implementación comenzará cuando el alcance inicial y las decisiones funcionales estén validados.

## Dirección tecnológica acordada

- Backend: Python.
- Base de datos: PostgreSQL.
- Aplicación web: React.
- Desarrollo local en Mac, sin Docker.

Las versiones concretas y herramientas complementarias se definirán al preparar el entorno.

## Principio de trabajo

Primero entender y validar el cuidado real; después diseñar los flujos y construirlos por etapas. Momento debe apoyar a las personas y equipos de cuidado. La IA puede asistir, pero no reemplaza el criterio profesional ni toma decisiones clínicas por su cuenta.
