# Aplicación web Momento

Aplicación web React y TypeScript. Vite dirige las solicitudes de /api al backend local de FastAPI.

## Preparar e iniciar

Desde esta carpeta ejecuta:

    npm install
    npm run dev

Abre http://127.0.0.1:5173. Para que la API aparezca disponible, inicia también el backend siguiendo backend/README.md. La comprobación PostgreSQL aparecerá pendiente hasta configurar la conexión local.

## Compilar

    npm run build
